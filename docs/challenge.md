# 赛题要求原文（挑战内容）

> 官方原文照录（来源：大赛组委会发布的赛题说明），未做改动。量化指标解读见 [靶场信息整理](modules/range.md) §1.3。

**1**、Agent 资产风险静态识别：选手需要全面识别系统中的 AI Agent、推理框架、模型、Skills、MCP 等关键资产，构建资产图谱，并能够识别因配置不当导致的风险，检测恶意 Skills、MCP 等供应链安全隐患。

**2**、Agent 运行时异常监控与阻断：针对漏洞利用和提示词攻击引发的高风险行为，实现检测、阻断与审计，重点针对两类场景：

（1）检测 Agent 框架或依赖组件在运行时被漏洞利用引发的异常行为

（2）检测提示词攻击导致的越权访问、敏感数据读取、数据外泄及恶意代码执行等行为

在识别到高风险行为后，阻断攻击链路或告警，阻断机制应保证正常业务可用性，同时需提供完整的攻击链路，包括应用内函数栈帧、提示词，工具调用链等审计日志，提供阻断决策的依据记录与可审计能力

### 挑战内容

**1**、Agent 资产风险识别能力：根据给定的环境，发现AI Agent相关资产（包括Agent、AI供应链组件、模型、工具等），并具备配置项安全检测能力，识别恶意Skills与MCP工具，要求资产盘点漏报率低于5%、准确率99%以上，资产风险识别准确率达到95%以上，漏报率低于5%。

**2、Agent风险监控与阻断能力**：监控 Agent 运行时风险，还原攻击链路，并对攻击进行检测和阻断。要求漏洞利用以及Agent异常行为检测和阻断误报率低于5%，检出95%以上，响应时间小于1秒，同时CPU占用率控制在5%以内，业务0中断影响
